# Signaler une faille de sécurité

LogIT sert à la traçabilité des interventions et à la conformité NIS2 : une faille peut exposer des informations sensibles sur l'infrastructure de ceux qui l'utilisent. Merci de la signaler **en privé**.

## Comment signaler

- Utilise le bouton **« Report a vulnerability »** de l'onglet **Security** du dépôt GitHub. Le signalement n'est visible que des mainteneurs.
- **N'ouvre pas d'issue publique** et n'utilise pas la fenêtre « Signaler un bug » de LogIT : ses signalements peuvent devenir des issues publiques.

Indique si possible la version concernée (`logit status`), les étapes pour reproduire et l'impact constaté. N'inclus aucune donnée réelle : utilise des données fictives.

## Versions prises en charge

Seule la dernière version publiée reçoit les correctifs de sécurité. Mettre à jour : `sudo logit update`.
